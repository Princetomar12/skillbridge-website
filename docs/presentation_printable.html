Motivation & Need

Problem Statement & Campus Challenges

Students often have groundbreaking project ideas but fail to execute due to three systemic bottlenecks:

🚫

1. Redundant Skill Teams

Student groups form based on friend circles rather than complementary competencies, resulting in teams with 4 backend coders and zero UI/UX or data specialists.

📢

2. Fragmented Discovery

Project recruitment happens across scattered WhatsApp, Telegram, or Discord chats with no structured tracking of domain categories or role requirements.

📉

3. The Execution Abyss

After team formation, students lack dedicated sprint tracking tools. Milestones are neglected, resulting in rushed submissions right before final exam evaluations.

Algorithm Design

Complementary Skill Matchmaking Algorithm

How SkillBridge prevents team skill imbalance and encourages multidisciplinary projects:

// Synergy Scoring Calculation
Score = 0; TotalChecks = 0;
For each role in project.openRoles:
  TotalChecks += 2.0;
  If student.hasSkill(role.skillNeeded):
    Score += 2.0; // Direct Fit
  Else If isComplementary(student, role):
    Score += 1.5; // High Synergy Pair
  Else:
    Score += 0.8; // Academic Baseline
MatchRate = min(98%, round(Score/TotalChecks * 100));

Direct Role Alignment (+2.0)

When an applicant's core expertise matches the exact unfilled technical role advertised by the leader.

Complementary Synergy (+1.5)

Rewards cross-discipline pairings (e.g. UI/UX Designer paired with a Backend system, or ML specialist with Data engineering).

Zero Skill Saturation

Discourages duplicate skill applications to ensure balanced teams with end-to-end capabilities.

Specifications

Technical Stack & System Requirements

Pure vanilla web standards ensuring zero dependency issues, high performance, and rapid deployment:

Software Technologies

  • Frontend Structure: Semantic HTML5 & accessible modals
  • Styling: Vanilla CSS3 (Custom design system, glassmorphism)
  • Application Logic: Modern JavaScript (ES6+), Event-driven SPA
  • Data Persistence: Web Storage API (localStorage)
  • Interactivity: HTML5 Drag-and-Drop Kanban API

Hardware & Deployment

  • Processor: Intel Core i3 (4th Gen) / AMD Ryzen 3 or higher
  • RAM: 4 GB minimum (8 GB recommended)
  • Browser Support: Google Chrome, Edge, Firefox, Brave
  • Local Server: Python HTTP Server (`python -m http.server 3000`)
  • Zero Build Step: Instant startup without npm dependency bloat
