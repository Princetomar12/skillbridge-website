Motivation & Need

The Real-World Campus Problem

1. Redundant Skill Teams

Students often form teams based purely on friendship rather than skill compatibility. A team with 4 backend coders and no UI/UX designer or data modeler struggles to finish.

2. Disorganized Project Discovery

Student ideas get lost in unorganized WhatsApp, Telegram, or Discord channels without structured skill tags, roles needed, or domain classification.

3. Post-Formation Execution Failure

Even after forming a group, students lack a dedicated lightweight sprint tracker. Tasks are forgotten, accountability drops, and projects are rushed right before academic submission deadlines.

Speaker Notes for Teacher:
"Studies show that over 65% of student hackathon and minor project teams fail not due to lack of coding skill, but due to skill overlap and zero task coordination. SkillBridge targets all three parts of this lifecycle."
Proposed Solution

The Three Pillars of SkillBridge

🔍

1. Idea Discovery

Structured project proposals with defined objectives, tech stacks, deadlines, and unfilled roles.

⚡

2. Synergy Match

Algorithmic matchmaking comparing student abilities with required project roles to output a Compatibility % score.

📋

3. Team Kanban

Integrated 4-column sprint task board (To Do, In Progress, Review, Done) with priority badges and assignees.

Speaker Notes for Teacher:
"Rather than just being a job board or just being a Trello clone, SkillBridge combines both discovery AND execution in one single academic ecosystem."

Once the leader clicks 'Accept', the applicant is added as a team member, and tasks can be assigned to them on the Sprint Kanban board."
Algorithmic Innovation

How the Complementary Fit Algorithm Works

Instead of basic keyword matching, SkillBridge prioritizes Complementary Synergy:

// Pseudo-code of SkillBridge Synergy Engine
Score = 0; TotalChecks = 0;
For each requiredRole in project.openRoles:
  If user.hasSkill(requiredRole.skillNeeded):
    Score += 2.0; // Exact direct match
  Else If isComplementaryPair(user.skills, project.techStack):
    Score += 1.5; // Synergy (e.g. Designer + Frontend, ML + Data)
  Else:
    Score += 0.8; // Baseline academic enthusiasm
MatchPercentage = (Score / TotalChecks) * 100;

Result: If a student specializes in UI/UX and a project urgently needs a designer, the match score jumps to 90-98%.

Speaker Notes for Teacher:
"Notice that our algorithm doesn't just look for duplicate skills. If a backend project needs a Figma designer, a designer will receive the highest match score, ensuring teams are balanced across all disciplines."
System Implementation

Core Modules & Live Interfaces

1. Explore & Discovery Feed

  • Search across project titles, tags, and technologies.
  • Filter by domain (AI/ML, Mobile, EdTech, Web3).
  • Live Matchmaking badges on every card.

Specifications

Hardware & Software Specifications

Technology Stack

  • HTML5: Semantic single-page layout & modals.
  • CSS3: Custom theme variables, glassmorphism, responsive grid.
  • Vanilla JavaScript (ES6+): Matchmaking logic, state management, drag & drop.
  • LocalStorage API: Offline-first persistent state storage.

System Requirements

  • Processor: Intel Core i3 (4th Gen) / AMD Ryzen 3+.
  • RAM: Minimum 4 GB (8 GB recommended).
  • Web Browser: Chrome 90+, Edge, Firefox.
  • Server: Python HTTP Server / VS Code Live Server.
Speaker Notes for Teacher:
"We intentionally chose a pure vanilla web architecture for zero dependency bloat, near-instant load speeds, and clean portability across any operating system."
Roadmap

Evolution into Major Project

SkillBridge is architected so that the current minor project seamlessly scales into a full-scale major project:

1. Fullstack Cloud Backend

Replace client LocalStorage with Node.js/Express REST APIs and PostgreSQL / MongoDB database with Prisma ORM.

2. Real-Time Team Chat

Embed WebSocket (Socket.io) channels within project workspaces for real-time team messaging and file sharing.

3. University SSO Integration

Authenticate student identity using College Roll Number and Institutional Google Workspace / LDAP accounts.

4. AI Proposal Assistant

LLM-powered tool to suggest project milestones, detect duplicate ideas across past batches, and draft project synopses.
